# Azeroth Survivors Stat Overlay

Customizable In-game stat overlay for Azeroth Survivors.
### Features

- **Real-Time Stat Display** – Displays your character's combat stats in an on-screen overlay, updating as new stat data becomes available.
- **Configurable Stat Visibility** – Choose which stats are displayed and hide any entries you don't need.
- **Custom Positioning** – Move the overlay anywhere on your screen, with options to lock its position once you're happy with the layout.
- **Appearance Customization** – Adjust the scale, width, font size, row height, padding, borders, and colors to suit your UI.
- **Multiple Styles** – Choose between a basic WoW-inspired appearance and an ElvUI-inspired style.
- **Additional Stats** – Supports extra stats provided by the game, allowing the overlay to display more than just a fixed set of values.
- **Persistent Character Data** – Remembers the last received stats for each character.
- **Reload Support** – Can automatically retrieve stats after a UI reload by briefly opening and closing the character panel.
- **Run Status** – Displays the current run phase alongside your character's stats.

### Configuration

Open the options panel using any of the following chat commands:

- `/statoverlay`
- `/sov`
- `/so`

From there, you can configure the displayed stats, overlay position, appearance, and reload behavior.

The overlay can also be shown or hidden whenever needed, with options for displaying raw values and adjusting the overall layout.
